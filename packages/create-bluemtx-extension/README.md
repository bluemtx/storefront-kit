# `create-bluemtx-extension`

Scaffold a **trusted Composition extension** (slot package) for BlueMTX standard storefronts.

This is not a full headless app. For full-custom storefronts, use [`create-bluemtx-storefront`](../create-bluemtx-storefront).

```bash
npx create-bluemtx-extension my-extension
```

Fallback (GitHub Release tarball):

```bash
npx --yes https://github.com/bluemtx/storefront-kit/releases/download/v0.2.2/create-bluemtx-extension-0.2.2.tgz my-extension
```

Extensions require platform approval before merchants can assign them to slots.
