# BlueMTX Nuxt Storefront Starter

External headless starter consuming `@bluemtx/storefront-sdk` + the BlueMTX Storefront Public API.

```bash
npx create-bluemtx-storefront my-store
cd my-store
cp .env.example .env
npm install
npm run dev
```

Fallback:

```bash
npx --yes https://github.com/bluemtx/storefront-kit/releases/download/v0.2.2/create-bluemtx-storefront-0.2.2.tgz my-store
```

Demonstrates: bootstrap/config, catalog list, localization fields, SEO meta hooks.  
Expand with cart/checkout/auth as needed — Commerce remains authoritative for checkout.

See [docs/getting-started.md](../../docs/getting-started.md).
